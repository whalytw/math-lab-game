# 數學實驗室｜高中數學複習挑戰

高中數學的課堂複習遊戲（由「指對數實驗室」擴充成整學期、多冊適用），目前收錄五冊：

| 設定頁選項 | 課本 | 單元 |
|---|---|---|
| 一上 | 數學 1（翰林） | 1-1～4-3（共 10 節） |
| 二上A版 | 數學 3A（龍騰） | 單元 1～10 |
| 二上B版 | 數學 3B（龍騰） | 單元 1～7 |
| 三上選修甲 | 選修數學甲(上)（南一） | 1-1～3-2（共 8 節） |
| 三上選修乙 | 選修數學乙(上)（南一） | 1-1～3-2（共 7 節） |

大螢幕分成左、中、右三區，三位同學同時上台、各玩各的；一位玩完就能立刻換下一位。

- 老師在設定頁用**下拉選單選冊數**、**勾選出題單元**、設定**每位同學總題數**，遊戲就從勾選的單元混合出題。
- 單元名稱和標題與課本相同。
- 純前端靜態網頁，**不需要安裝、不需要編譯**，放上 GitHub Pages 就能用。
- 也可以直接在電腦上雙擊 `index.html` 開啟（教室網路斷線時的備案）。
- 支援 Chrome、Edge。

## 一、放上 GitHub Pages

### 方法 A：用網頁上傳（最簡單）

1. 在 GitHub 建立新的 repository，例如 `math-lab`，設為 **Public**。
2. 進入 repository → **Add file → Upload files**。
3. 把解壓縮後 `math-lab` 資料夾「裡面」的所有檔案與資料夾拖進去（`index.html` 要在最上層，不要多包一層資料夾）。
   - 共約 60 個檔案，一次就能上傳完（GitHub 網頁一次上限 100 個）。
   - 資料夾裡有一個隱藏檔 `.nojekyll`，如果檔案總管沒顯示也沒關係，少了它網站一樣能運作。
4. 按 **Commit changes**。
5. 到 **Settings → Pages**：
   - Source 選 **Deploy from a branch**
   - Branch 選 **main**、資料夾選 **/ (root)**，按 **Save**。
6. 約 1 分鐘後，網址會是：`https://你的帳號.github.io/math-lab/`

### 方法 B：用 git

```bash
cd math-lab
git init
git add .
git commit -m "數學實驗室"
git branch -M main
git remote add origin https://github.com/你的帳號/math-lab.git
git push -u origin main
```

之後一樣到 **Settings → Pages** 開啟（同上第 5 步）。

## 二、教室設定（Surface Pro 8 ＋ ViewSonic IFP8653）

### 1. 連線：上課請用 USB-C 線

- 用全功能 USB-C 線連接時，畫面與**觸控**都會走同一條線，三人同時觸控最穩定。
- AirSync 無線投影通常只傳畫面，觸控可能無法回傳到筆電，延遲也較高，建議只作備用。

### 2. 先做一次「觸控測試」

1. 開啟遊戲 → **長按右上角「⚙ 設定」2 秒** → 按「開始觸控測試」。
2. 請三位同學同時在左、中、右區拖曳手指，畫面上應該同時出現三個圓圈，右上角「最多同時」要到 3。
3. 如果觸控位置跟手指對不上（例如點大螢幕卻點到筆電螢幕的位置）：
   Windows「控制台 → 平板電腦設定 → 設定…」→ 依照提示在大螢幕上點一下，讓 Windows 知道觸控是屬於哪個螢幕。

### 3. 建議關閉 Windows 的多指手勢

學生多指同時操作時，Windows 可能誤判成三指／四指手勢而切換視窗：

- Windows 11：**設定 → 藍牙與裝置 → 觸控 → 關閉「三指和四指觸控手勢」**
- （進階、選用）從螢幕邊緣滑入叫出小工具／通知中心：可用群組原則
  「電腦設定 → 系統管理範本 → Windows 元件 → 邊緣 UI → 允許邊緣撥動」設為「已停用」。
  Windows 家用版沒有群組原則編輯器，可略過此項。

### 4. 用「Kiosk 模式」開啟（最能防止學生亂點）

Kiosk 模式沒有網址列、分頁和瀏覽器選單，學生點不出任何瀏覽器功能。在桌面建立捷徑，「目標」填入下列其中一行（網址換成你的）：

**Chrome**

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --user-data-dir="C:\MathLabKiosk" https://你的帳號.github.io/math-lab/
```

**Edge**

```
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk https://你的帳號.github.io/math-lab/ --edge-kiosk-type=fullscreen --no-first-run
```

- 離開 Kiosk 模式：按鍵盤 **Alt＋F4**。
- Chrome 的 `--user-data-dir` 會另開一個獨立的瀏覽器設定檔，這樣即使 Chrome 已經開著也能進入 Kiosk 模式。
- Edge 若已經開著，Kiosk 參數會被忽略：請先關掉所有 Edge 視窗；必要時到 `edge://settings/system` 關閉「啟動提升」。
- 遊戲設定存在「瀏覽器設定檔」裡，Kiosk 視窗用的是獨立設定檔，所以**請在 Kiosk 視窗裡調整設定**。

不使用 Kiosk 時，也可以按畫面右上角「⛶ 全螢幕」。全螢幕時要**長按 1.5 秒**才會離開，避免學生誤觸。

## 三、上課怎麼玩

1. 老師先長按「⚙ 設定」2 秒，在「出題範圍」用下拉選單選冊數（一上／二上A版／二上B版），再勾選單元、選每位同學的總題數（3～12 關）。
2. 三位同學各站一區，按「開始挑戰」。
3. 每關一道挑戰題，時間顯示在各區上方。第 1 關固定是「真偽閘門」（是非觀念題）暖身，最後一關盡量排「骨牌魔王關」。
4. 玩完會顯示總分與每關結果（每關前面的小數字是單元），下方「再玩一次」約 3 秒後亮起，下一位同學按它就直接開始。
5. 同學中途離開：教師到設定頁「重新開始」把該區回到開始畫面。

### 出題方式

- 勾選的單元**平均分配**到每一關後打亂順序，盡量不連續出同一單元。
- 每關的玩法會輪流使用，盡量不重複；是非題每人約佔 1/4 的關數。
- 同一位同學的一場挑戰中不會出現重複題目；三區也會避開最近出過的題目，後面的同學看前面的人玩也抄不到答案。
- 例：二上A版段考考單元 5、6、7，選「二上A版」、勾選這三個單元、總題數選 8，每位同學就從三個單元混合抽 8 關。
- 每冊勾選的單元分開記住，換冊再換回來時，原本勾選的單元還在；某冊從沒勾選過時，預設為全冊。

### 計分規則

| 情況 | 結果 |
|---|---|
| 答對 | 15 分＋剩餘秒數（剩餘秒數會化成光點飛進分數） |
| 主動按「求救卡」 | 出現提示，扣 10 秒（每關一張） |
| 第一次答錯 | 自動用掉求救卡：出現提示、扣 10 秒，可以再答 |
| 再次答錯，或時間到 | 本關 0 分，顯示正解，5 秒後自動進入下一關（也可按「下一關」） |
| 剩 10 秒以內 | 求救卡變灰；此時答錯直接結束本關 |

- 轉場、慶祝與展示正解的時間不計入作答秒數。
- 開啟設定頁時，三區全部暫停。

### 華麗特效

「特效」選「華麗」時，在完整特效之外加上 3D 特效。（預設就是「華麗」；舊版存過的「完整」第一次開啟時會自動改成「華麗」，選「精簡」的不受影響。）每個時機有兩種特效，隨機決定，同一區連續兩次不會一樣：

| 時機 | 特效 A | 特效 B |
|---|---|---|
| 關卡轉場 | 數字方塊從遠處翻滾飛入，背景是星點隧道 | 本單元的代表曲線（正弦、指數、對數、多項式、圓…）化成發光管線，在空中轉一圈 |
| 答對 | 3D 彩紙翻轉飄落 | 發光多面體爆開，再飛進分數欄 |
| 答錯／時間到 | 畫面向後傾斜晃動，題目區裂成紅色碎片掉落 | 紅色立體符號（✕、π、√…）掉下來彈跳 |
| 求救卡 | 提示框 3D 翻面＋星點 | 提示框從下方立起來＋聚光燈 |
| 總分畫面 | 旋轉的 3D 獎盃＋聚光燈（依稱號分金、銀、銅） | 立體煙火（稱號越高越多發） |

另外，選項卡片、按鈕、轉場數字在「華麗」時會有立體的傾斜與翻轉動畫。

**效能設計（讓 Surface Pro 8 接大螢幕也跑得順）**

- 整個畫面只有一張 3D 畫布，三區共用；以較低解析度（60% × 「畫面解析度」）繪製再放大。
- 3D 只在轉場、答對、答錯、求救、總分時播放；作答時 3D 畫布隱藏、完全不繪製。
- 碎片、彩紙合併成一個網格一次畫完；不用陰影與後製效果。
- 三區同時播放的重特效最多約 2 個，超過時改播較輕的那一種或延後 0.3 秒。
- 持續偵測流暢度，連續 2 秒低於每秒 45 格就**自動改回「完整」**，設定頁會顯示提示；重新選「華麗」即可再開啟。
- 電腦不支援 3D（WebGL）時，「華麗」會以「完整」顯示。

**上課前請先在教室測一次**：接好大螢幕 → 長按「⚙ 設定」→「觸控與效能測試」按「華麗特效測試」。三區會同時播放最重的 3D 特效 30 秒，結束後顯示平均與最低每秒畫面數：

- 平均 45 以上、最低 35 以上：順暢，可以使用「華麗」。
- 略低：把「畫面解析度」調成 75% 再測一次。
- 仍然不順：使用「完整」。

想在遊戲中一直看到每秒畫面數，可在網址後面加上 `?fps=1`。

## 五、修改或新增題目

所有題目都放在 `js/banks/` 資料夾；玩法程式（`js/levels/`）裡沒有任何題目。

- `js/banks/1A.js`：一上（數學 1，翰林）1-1～4-3 的全部題目。
- `js/banks/3A.js`：二上A版（數學 3A，龍騰）單元 1～4、8～10 的全部題目，以及單元 5～7 的是非題。
- `js/banks/3A-u05-07.js`：二上A版單元 5～7 原有題庫（由指對數實驗室搬過來，分簡單／標準／挑戰三組，寫法見檔案開頭說明）。
- `js/banks/3B.js`：二上B版（數學 3B，龍騰）。用 `copy(...)` 沿用A版相同內容的題目，再用 `add(...)` 補上B版自己的題目。
- `js/banks/4A.js`：三上選修甲（選修數學甲(上)，南一）。只有選修甲有教的題目用 `A(...)` 標記。
- `js/banks/4B.js`：三上選修乙（選修數學乙(上)，南一）。用 `copy(...)` 沿用選修甲的題目（自動排除 `A(...)` 標記的題目），再補上選修乙自己的題目。

每個題庫檔開頭的 `LG.bank.book(...)` 登記這一冊的名稱（設定頁下拉選單的選項）、各單元名稱與快捷鍵分組。

數學式用 `$...$` 包起來，寫法與 LaTeX 相同。注意：JavaScript 字串裡的反斜線要寫兩個，例如 `'$\dfrac{\pi}{6}$'`。

| 寫法 | 題型 |
|---|---|
| `T(敘述, true/false, 理由)` | 是非題，每關抽 3 句 |
| `C(題目, [正解, 干擾1, 干擾2, 干擾3], 提示, 解說)` | 單選題／魔王題，**選項第一個是正解**，畫面上會自動打亂 |
| `M(算式, 值, 提示, 題目說明)` | 配對題，每關抽 3 個值不同的算式；同一單元的配對題「題目說明」要一致（例如 `'它的週期'`） |
| `N(題目, 答案, 單位, 望遠鏡顯示, 揭曉算式, 提示, 解說)` | 數值題，答案必須是正整數（1～999） |
| `G({ prompt, win, opts: [正解圖, 干擾, 干擾], hint, explain })` | 圖形題 |
| `K({ prompt, win, params, ans, plot, target, hint, explain })` | 參數調整題 |

每段開頭的 `add(單元, 玩法, [...])` 決定題目屬於哪個單元、用哪種玩法。加完題目，設定頁的題數會自動更新。
以後要加其他課本（例如二下），照 `js/banks/` 裡的格式另寫題庫檔，並在 `index.html` 加一行 `<script src="js/banks/檔名.js"></script>`，下拉選單就會多一個選項，不需要修改任何玩法程式。

## 七、疑難排解

| 狀況 | 處理方式 |
|---|---|
| 觸控沒反應或點不準 | 確認使用 USB-C 線；用設定頁的「觸控測試」檢查；必要時做「平板電腦設定」的觸控對應 |
| 三人同時操作時卡頓 | 設定頁把「畫面解析度」調成 75% 或 50%，「特效」改成完整或精簡 |
| 特效自己從「華麗」變回「完整」 | 這是自動降級：畫面連續 2 秒不夠順暢。可先做「華麗特效測試」，或把「畫面解析度」調低後再選「華麗」 |
| 學生不小心點到別區 | 每根手指只會作用在按下時的那一區，手指滑到隔壁區也不會影響別人 |
| 手掌碰到螢幕造成誤觸 | 「手掌誤觸過濾」改成嚴格 |
| 骨牌魔王關沒有 3D 畫面 | 電腦不支援 WebGL 時會自動改用 2D 骨牌動畫，遊戲照常進行 |
| 網路斷線 | 直接雙擊電腦上的 `index.html` 開啟（設定需在該視窗重新調整） |
| 設定頁內容太多、下方被切掉 | 每一欄都可以上下捲動：手指在該欄上下滑動，或用滑鼠滾輪 |
| 更新檔案後畫面還是舊的 | 設定頁標題旁會顯示「版本 …」，可以確認這台電腦跑的是不是最新檔案。若檔案放在 Google 雲端硬碟，另一台電腦要等雲端同步完成才會拿到新檔；同步完成後按 Ctrl＋F5 重新整理 |
